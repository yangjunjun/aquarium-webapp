# 一方水境：需求、Technical Spec 与任务记录

## 需求
- REQ-01：无需登录，打开即可观看 8 尾、3 个配色品种的鱼、摇摆水草、气泡与光束。
- REQ-02：点击鱼缸或投喂按钮产生鱼食；鱼主动靠近并吃掉鱼食。鱼食有数量上限与过期时间。
- REQ-03：添加鱼（最多 24 尾）、昼夜灯光、暂停/继续、清理鱼食、确认后重置。
- REQ-04：自动保存鱼群和灯光；损坏数据或禁用存储不影响使用；兼容桌面和手机，按钮和投喂支持键盘。
- 边界：这是休闲视觉模拟，无真实生态数值、账户、后端、音频或网络素材依赖。仓库名 aquarium-webapp；用户创建为公开仓库，保留该可见性。

## Technical Spec
Canvas 2D + 原生 ES Modules。`simulation.js` 负责归一化坐标、边界转向、鱼食吸引/消费和持久化校验；`app.js` 负责渲染、UI 与 localStorage；`style.css` 负责响应式布局。时间步长限制 50ms，隐藏页面停止推进，像素比限制 2。状态包含 version、fish 与 night；暂停和鱼食不持久化。保存失败显示提示。最大 24 尾鱼和 70 粒鱼食限制计算量。无第三方依赖和构建步骤；Node 静态服务器仅用于本地开发，部署时直接托管静态文件。
