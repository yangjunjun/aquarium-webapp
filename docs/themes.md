# 鱼缸主题：需求、Technical Spec 与任务计划

## 需求与验收
- TH-01：自然溪流、科幻实验舱、克苏鲁深海是三个完整世界，环境、底床、装饰、鱼、蟹、鱼食、粒子和界面均随主题改变。
- TH-02：主题预览卡片和全屏内选择器可用键盘操作；切换保留鱼、蟹、位置与正在下沉的鱼食。主题和减少动态偏好可保存。
- TH-03：约 500ms 淡入过渡；快速连续切换以最新选择为准；旧存档默认自然主题，未知主题安全回退，保留旧鱼群。
- TH-04：明亮/幽暗使用主题对应光照；暂停停止生物和所有场景动画；减少动态禁用扫光、脉冲和巨物掠影，并降低装饰运动。默认遵循系统减少动态偏好。
- TH-05：手机、全屏和页面展开模式可操作；固定粒子数量、最高 2 倍像素比，保持无构建/零生产依赖。

## 技术设计
`simulation.js` 保留统一运动模型。`preferences.js` 负责主题 ID、保存偏好和受限过渡状态。
`renderer.js` 管理画布，主题模块实现 `background(ctx, scene)`、`fish(ctx, fish, scene)`、`crab(ctx, crab, scene)`、`food(ctx, pellet, scene)`。scene 包含尺寸、模拟时间、装饰时间、光照、减少动态与固定随机种子场景数据。所有绘制隔离 save/restore。
静态 UI 的 CSS 变量按 body data-theme 设置。预览使用真实渲染器画到小画布，避免外部图片。单一模拟时钟由暂停/页面可见性统一控制；减少动态仅改变装饰时钟和特殊效果，不改变生物移动。
localStorage 键保留 aquarium-v1，增加 theme 和可选 reducedMotion；旧版 version=1 继续读取。重置恢复居民，保留已选主题和动态偏好。
半秒过渡采用当前画布截图覆盖新画面并逐帧淡出，最多一个临时画布；减少动态时立即切换，暂停时不推进过渡；暂停状态下选主题会立即切换，暂停操作也会结束尚未完成的过渡，以便清楚查看当前世界。

## 提交计划
1. 主题基础：抽离自然绘制、接入选择与存档、兼容测试。
2. 科幻主题：实验舱、管道、能量柱、机械/透明鱼、机械蟹、营养胶囊。
3. 克苏鲁主题：遗迹、符文、触须、深海生物、岩壳蟹、孢子和低频巨影。
4. 体验与验证：真实场景预览、过渡、全屏控制、减少动态、手机布局、回归测试与部署。

## 验证策略
Node 内置测试覆盖存档迁移、未知主题、居民对象保留、过渡和减少动态，以及原有模拟测试。渲染契约检查覆盖所有主题的明暗模式和减少动态。若能使用本地浏览器，则验证切换、投喂、暂停、全屏、刷新和移动布局；缺少浏览器时明确记录，不能用模拟 DOM 测试声称真实浏览器通过。
